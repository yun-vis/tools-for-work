## Overview

[Anthropic](https://www.anthropic.com/) offers four ways to interact with Claude, ranging from simple chat to autonomous coding tools.

---

## 1. Claude Chat (Web & Desktop)
The standard conversational interface for general use.
*   **Best for:** Brainstorming, writing, quick research, and analyzing manually uploaded files.
*   **Key Feature:** Simple, intuitive Q&A without direct local file system access.
*   **Availability:** Web browser (Claude.ai) or the Claude Desktop app.

## 2. Claude Cowork (Desktop App)
An agentic assistant for non-technical knowledge work.
*   **Best for:** Organizing local folders, managing tasks, and creating complex documents (like Excel sheets).
*   **Key Feature:** **Local file access** to folders you authorize. It can read, create, and edit files on your computer.
*   **Safety:** Runs code in an isolated virtual machine (VM) on your system.

## 3. Claude Code (Desktop App)
A visual coding agent built directly into a dedicated tab in the desktop app.
*   **Best for:** Developers who want an autonomous coding partner with a graphical interface.
*   **Key Feature:** Includes a **file tree sidebar**, split-view for planning, and a **preview pane** for web apps.
*   **Workflow:** Uses Git worktrees to handle multiple tasks simultaneously.

## 4. Claude Code CLI (Terminal)
The terminal-based version for technical power users.
*   **Best for:** Heavy-duty software engineering, scripting, and automation pipelines.
*   **Key Feature:** Supports **headless mode** (running unattended) and piping terminal outputs directly to the model.
*   **Pricing:** Generally uses pay-as-you-go **API pricing**, unlike the subscription-based apps.
